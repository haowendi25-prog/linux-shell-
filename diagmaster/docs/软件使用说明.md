# DiagMaster 软件使用说明

---

## 一、系统要求

| 项目 | 要求 |
|------|------|
| **操作系统** | Ubuntu 18.04+ / Debian 10+ / WSL (Ubuntu) |
| **Shell** | Bash 4.0+ |
| **依赖** | 无（所有工具均为 Linux 系统自带） |
| **磁盘空间** | < 10 MB |
| **权限** | 普通用户即可运行；部分功能（dmesg、/var/log）需 root 或 sudo |

## 二、安装

### 2.1 下载项目

```bash
# 克隆仓库
git clone https://github.com/haowendi25-prog/linux-shell-.git ~/diagmaster/diagmaster
```

如果已有压缩包，解压到任意目录即可。

### 2.2 赋予执行权限

```bash
cd ~/diagmaster/diagmaster
chmod +x diagmaster.sh
chmod +x modules/*.sh
chmod +x lib/*.sh
chmod +x tests/*.sh tests/lib/*.sh
```

### 2.3 验证安装

```bash
bash diagmaster.sh
# 应看到登录界面：
# ==================================================
#     DiagMaster 服务器一键多维智能诊断工具箱 v2.0
# ==================================================
# [安全认证]
# 请输入管理员账户:
```

## 三、运行

### 3.1 交互式运行（推荐）

```bash
cd ~/diagmaster/diagmaster
bash diagmaster.sh
```

登录后进入主菜单，输入数字 1-8 选择功能：
```
 1) 服务器节点资产管理
 2) 多进程性能指标并行监控
 3) 内核日志清洗与安全审计
 4) 智能化磁盘清理与自愈
 5) 启动自动巡逻巡检
 6) 后台巡逻守护（daemon）
 7) 关于项目技术架构与分工
 8) 安全退出
```

### 3.2 命令行模式

```bash
# 执行一次性巡逻检查
bash diagmaster.sh --patrol

# 启动后台巡逻守护进程
bash diagmaster.sh --daemon

# 停止后台巡逻守护进程
bash diagmaster.sh --stop

# 查看守护进程状态
bash diagmaster.sh --status

# 显示帮助
bash diagmaster.sh -h
```

### 3.3 直接运行单个模块

```bash
# 性能采集
bash modules/collector.sh

# 日志审计
bash modules/log_analyzer.sh

# 自动巡逻（不经过主菜单）
bash modules/patrol.sh
```

### 3.4 定时任务（crontab）

```bash
crontab -e
# 添加：每天 8:00 执行巡逻
0 8 * * * cd ~/diagmaster/diagmaster && bash modules/patrol.sh >> logs/cron_patrol.log 2>&1
```

## 四、配置

配置文件：`config/diag.conf`

### 4.1 阈值配置

```bash
CPU_WARN_THRESHOLD=80       # CPU 告警阈值 (%)
MEM_WARN_THRESHOLD=85       # 内存告警阈值 (%)
DISK_WARN_THRESHOLD=90      # 磁盘告警阈值 (%)
```

### 4.2 认证配置

```bash
ADMIN_USER="admin"          # 登录用户名
ADMIN_PASS="12345"          # 登录密码（生产环境请修改）
```

### 4.3 巡逻配置

```bash
SERVICES_TO_CHECK="sshd cron"    # 要检查的服务列表
PROCESSES_TO_CHECK="sshd"        # 要检查的进程列表
```

### 4.4 告警配置

```bash
ENABLE_ALERT=false              # 开启邮件告警：true/false
ALERT_EMAIL="admin@example.com" # 告警接收邮箱
```

**配置修改后无需重启**，下次运行自动生效。

## 七、常见问题排查

### 问题1：运行时提示 "Permission denied"
**解决**：执行 `chmod +x diagmaster.sh modules/*.sh lib/*.sh tests/*.sh tests/lib/*.sh`

### 问题2：忘记密码
**解决**：编辑 `config/diag.conf`，修改 `ADMIN_PASS` 的值，或删除该行使用默认密码 `12345`

### 问题3：OOM/SSH 数据为 0 但应该是非零
**原因**：读取 `dmesg` 或 `/var/log/auth.log` 需要 root 权限。
**解决**：使用 `sudo bash diagmaster.sh` 运行

### 问题4：服务检查失败（systemctl not found）
**影响**：非 systemd 系统（如 WSL1、某些 Docker 容器）中 systemctl 不可用。
**自动降级**：脚本会自动使用 `pgrep` 替代 `systemctl` 检查进程。

### 问题5：邮件告警未发送
**检查步骤**：
1. 确认 `ENABLE_ALERT=true`
2. 确认 `mail` 命令可用：`which mail` 或 `sudo apt install mailutils`
3. 检查 `ALERT_EMAIL` 是否正确

## 八、安全注意事项

1. **修改默认密码**：生产环境中请务必修改 `config/diag.conf` 中的 `ADMIN_PASS`
2. **配置文件权限**：建议 `chmod 600 config/diag.conf` 防止密码泄露
3. **磁盘清理确认**：磁盘清理功能会清空 `/tmp`，请确认无重要文件后再执行
