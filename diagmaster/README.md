## 这玩意儿是干嘛的？

用大白话说：**DiagMaster 就是个服务器"体检仪"**。

你只需要在终端里敲一行命令，然后像看电视遥控器一样按数字键，它就能帮你：

| 功能 | 通俗解释 |
|------|----------|
| 🖥️ **性能监控** | 看看 CPU 累不累、内存够不够、磁盘满没满 |
| 🔍 **日志审计** | 检查有没有人偷偷暴力破解你的服务器密码 |
| 🧹 **磁盘清理** | 一键清空系统垃圾文件，释放空间 |
| 🚨 **自动巡逻** | 定时全身体检，有毛病立刻告诉你 |
| 📋 **节点管理** | 管理多台服务器，像电话簿一样记下它们的地址 |

**不需要你会 Linux 命令**，全程菜单操作，输入数字就行。

## 主菜单都干什么？

### 1. 服务器节点资产管理

> 通俗理解：**像一个电话簿，记下你管理的所有服务器地址**

子菜单：
```
 1) 查看当前受控节点列表
 2) 新增受控服务器节点
 3) 删除失效服务器节点
 4) 返回主菜单
```

数据保存在 `data/nodes.txt` 文件里。

### 2. 性能指标并行监控

> 通俗理解：**同时量三个指标，看看服务器"累不累"**

同时检测 CPU 使用率、内存使用率、磁盘使用率。

| 指标 | 绿色安全 | 黄色警告（默认） | 红色危险 |
|------|-----------|-----------------|----------|
| CPU | < 80% | 80%-95% | > 95% |
| 内存 | < 85% | 85%-95% | > 95% |
| 磁盘 | < 90% | 90%-95% | > 95% |

> 阈值可以在 `config/diag.conf` 里改

### 3. 内核日志清洗与安全审计

> 通俗理解：**像保安查监控，看看有没有坏人试图破解你的服务器**

自动检查：**OOM 事件**（内存不够杀进程）和 **SSH 爆破**（暴力猜密码）。

检测完成后自动生成 Markdown 报告到 `reports/` 文件夹。

### 4. 智能化磁盘清理

> 通俗理解：**一键倒垃圾，清理系统临时文件**

只会清理 `/tmp` 下的临时文件，不会动你的重要数据。

### 5. 自动巡逻巡检

> 通俗理解：**医生查房，一次性检查 6 个项目，全部正常才放心**

一键检查：

| 序号 | 检查项 | 检查什么 |
|------|--------|----------|
| 1 | CPU 使用率 | 是否超过阈值（默认 80%） |
| 2 | 内存使用率 | 是否超过阈值（默认 85%） |
| 3 | 磁盘使用率 | 是否超过阈值（默认 90%） |
| 4 | 关键服务 | sshd、cron 是否在正常运行 |
| 5 | 关键进程 | 重要进程是否存在 |
| 6 | 日志异常 | 是否有 OOM / SSH 爆破 |

- ✅ `巡逻完成：系统状态正常。` — 一切安好
- ⚠️ `巡逻完成：发现异常项，请查看报告。` — 去 reports 文件夹看报告

### 6. 后台巡逻守护（daemon）

守护进程模式，可后台持续巡检，支持启动/停止/状态查看。

### 7. 关于项目

显示团队信息和技术栈。

## 怎么修改配置？

配置文件：**`config/diag.conf`**

```bash
# 性能阈值
CPU_WARN_THRESHOLD=80
MEM_WARN_THRESHOLD=85
DISK_WARN_THRESHOLD=90

# 登录账号密码（强烈建议修改）
ADMIN_USER="admin"
ADMIN_PASS="12345"

# 巡逻要检查的服务和进程
SERVICES_TO_CHECK="sshd cron"
PROCESSES_TO_CHECK="sshd"

# 邮件告警开关
ENABLE_ALERT=false
ALERT_EMAIL="admin@example.com"
```

**改完配置后不需要重启任何东西**，下次运行自动生效。

## 常见问题（QA）

### Q: 运行时报错 "Permission denied" 怎么办？

```bash
chmod +x diagmaster.sh modules/*.sh lib/*.sh tests/*.sh tests/lib/*.sh
```

### Q: 忘记密码了怎么办？

打开 `config/diag.conf`，找到 `ADMIN_PASS` 那行改掉，或者删除该行用默认密码 `12345`。

### Q: 我想检查更多服务怎么办？

修改 `config/diag.conf` 里的 `SERVICES_TO_CHECK` 变量：
```bash
SERVICES_TO_CHECK="sshd cron nginx mysql"
```

### Q: 邮件告警怎么开启？

1. 先确保服务器装了 `mail` 命令：`sudo apt install mailutils`
2. 修改 `config/diag.conf`：`ENABLE_ALERT=true` 和 `ALERT_EMAIL` 改为你的邮箱
3. 巡逻发现异常时，会自动发邮件给你

### Q: 怎么让巡逻定时自动运行？

```bash
crontab -e
# 添加：每天早上 8 点自动巡逻
0 8 * * * cd ~/diagmaster/diagmaster && bash modules/patrol.sh >> logs/cron_patrol.log 2>&1
```

### Q: 运行会不会搞坏我的服务器？

**不会**。这个脚本只做**读取和报告**，唯一的"写入"操作是清理 `/tmp`（需手动确认 y/n）、生成报告文件和写运行日志。
